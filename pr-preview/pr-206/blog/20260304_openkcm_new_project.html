Open Key Chain Manager has been accepted into NeoNephos ​

We are proud to announce that Open Key Chain Manager has been accepted into NeoNephos!

OpenKCM is a data encryption key management solution, implementing a hierarchical key derivation system that wraps internal encryption keys with customer-managed root keys stored in external keystores , exposing key operations via KMIP protocol.

OpenKCM is the first project that has not been there from the start and therefore passed all many necessary steps prior to being accepted into NeoNephos. You can look their project proposal video at the TAC here. Or, you can learn how to introduce your own project into NeoNephos by reading this short guide.

We are happy have grown to an additional project and now possess an additional building block in our cloud-native fabric.
