# MCK Meeting: Sovereign & Open-Source Cloud-Native Tooling
Join us for a session on two open-source projects advancing sovereign, vendor-neutral cloud-native infrastructure.

First, Valentin Küchler, Henry Richter, and Artem Lytvynov present Thalamus, an open-source inference platform for sovereign LLM serving on Kubernetes – offering one API for model management and an OpenAI-compatible API for consumption, built on open standards like llm-d and vLLM. Includes an introduction and live demo.

Then, Augustin Husson (founder of Perses, Lead Principal Engineer at Amadeus) and Akshay Iyyadurai Balasundaram (SAP Cloud Infrastructure – Observability) introduce Perses, a Kubernetes-native dashboarding tool that brings metrics, logs, traces, and profiles together in one place – including its open-source journey, a live demo, and what’s next.

Each session runs 30 minutes including Q&A. Come learn, see live demos, and ask your questions – everyone is welcome. We're meeting on October 20 at 10AM.
